# Стан Playboard — 11.10.2026

Публічна beta працює на https://playboard-rc19.onrender.com: Render Free, Neon Frankfurt і Brevo HTTPS. Платні ресурси не створювалися. Користувач дозволив push коду в andrew-berezovskyi/playboard. Запуск: http://localhost:5173, API 3001, PostgreSQL 54329. Міграції 0001–0007 застосовані локально; тестова БД окрема.

## Етапи

0–1: архітектура, адаптивний каркас, реальна PostgreSQL-авторизація, підтвердження/reset пошти, три сторінки різного наповнення, Grid/Flex/media queries.

2: шахи у локальній beta — спеціальні ходи, draw claims/automatic draws, три worker-боти, приватні кімнати, справжній matchmaking, таймери, reconnect/restart, PGN і replay, реванш за згодою обох. Рідкісні FIDE dead-position та side-specific timeout випадки залишаються відкритими.

3: шашки-64 у локальній beta — backward captures, flying kings, повна серія, promotion під час серії, blockers до її завершення, лічильники нічиїх; multiplayer/bots/replay. Спеціальна негайна IDF-нічия без додавання з винятком очевидного виграшу ще потребує адаптера; повної спортивної сертифікації не заявлено.

4: Wayline v1 — десять власних карток, обмін, послідовний relay, capture navigator, вимушені паси, повторення і ліміт ходів; online і три боти. Конкурентний баланс і перевірка назви ще не підтверджені тривалим тестуванням.

5: 24 інтерактивні задачі трьох ігор, законна потрібна дія замість кнопки Next, прогрес/щоденний виклик, власний SVG-провідник із реакцією на успіх.

6: автоматичний гість; атомарне перенесення його кімнат у новий акаунт; профілі, редагування, приватність, пароль/видалення, налаштування фігур/дошки/звуку/анімації. Glicko-2, окремі пули/історія, XP/result ledgers, місячні ліги, календарні timezone streaks, досягнення. Друзі, блоки, запрошення, owned notifications, consented online і спільні матчі. Базовий anti-farming — три винагороджувані партії однієї пари за день; повне виявлення пов’язаних акаунтів залишається відкритим.

7: локальні typecheck/lint/build та тести проходять. Автоматичний axe-аудит перевіряє 8 сторінок у двох темах і дошки шашок/Wayline. Підготовлено CI-файл і Pages headers. Фізичні пристрої/Safari та ручний WCAG-аудит не перевірені. Мобільні Firefox/WebKit, Lighthouse, backup/restore і maintenance перевірені локально; production proxy/SMTP/TLS/scheduling та remote CI ще потребують перевірки.

## Перевірки

- npm run check: успішно; 60/60 Vitest, реальний PostgreSQL, frontend/backend build, TypeScript strict і ESLint.
- Повна браузерна серія: 14/14 Playwright у Chromium, включно з двома клієнтами, reconnect, draw/rematch, registration/logout, уроком і responsive matrix.
- Автоматичний WCAG-аудит: 0 знайдених порушень у перевірених станах; це не сертифікація повної доступності.
- Ширини: 320/375/390/430/768/1024/1440/1920px; landscape 844×390; окремі touch layouts для трьох дощок.
- npm audit: 0 відомих вразливостей на момент перевірки; це не повний security audit.
- Побудований worker шашок окремо повернув законний хід.
- Версія правил збережена в партії; невідома версія не приймає ходів. Перенесення гостя, exactly-once XP/рейтинг, приватність, online consent і timezone перевірені інтеграційно.

## Дизайн

Playboard + власний мінімалістичний board mark, Fixel локально з SIL OFL, графітові поверхні/Navy акценти. Прапор відповідає поточній мові. Профіль — компактний аватар, вихід у налаштуваннях. Згенеровані растрові картинки вилучені з public; screenshots показують реальний UI.

Це основний працездатний функціональний зріз, а не виконання всіх release-критеріїв ТЗ. Подробиці й обмеження: PLATFORM_IMPLEMENTATION.md, GAME_RULES.md, SECURITY.md, DEPLOYMENT.md. Перед GitHub ще потрібен дозвіл користувача та PUBLICATION_CHECKLIST.

Актуальні доповнення, фінальні результати й залишок ТЗ: ITERATION_2026-10-11.md. README доступний англійською й українською. Фінальна повна браузерна серія: 14/14. Lighthouse mobile: 90/100/100; результати лабораторні, не польові Core Web Vitals.
## Публічне розгортання — 11.10.2026

Усі сім міграцій виконані в Neon, HTTPS і БД працюють. Публічно перевірені всі три боти, приватна WebSocket-партія двох гостей та reconnect зі збереженим ходом, Secure/HttpOnly cookies, CSP і закриті службові файли. Власник отримав лист реєстрації й підтвердив пошту. Локальні перевірки: 66 тестів, typecheck/lint/build; GitHub CI: 14 браузерних сценаріїв. Документацію впорядковано, робочі звіти перенесено в docs/notes.

Залишаються операційна перевірка визначення IP за proxy, розклад backup/квоти, окрема доставка reset-листа, фізичні пристрої та раніше задокументовані обмеження правил. Попередні розділи описують стан до розгортання.
