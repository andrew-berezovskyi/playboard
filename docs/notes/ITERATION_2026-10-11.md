# Ітерація 11.10.2026

## Реалізовані доповнення

- Три послідовні курси поверх 24 законних інтерактивних задач. Наступний крок відкривається після виконання; сервер перевіряє попередні відповіді. Збережені уроки дають змогу продовжити курс зареєстрованому користувачу. Повторення доступне в каталозі уроків.
- Пояснення кожного правила й помилкового рішення українською та англійською. Назви карток Wayline локалізовано.
- Реальні навчальні партії з початковими ботами. Довідка доступна під час гри; приклад допустимого ходу — лише в навчальному режимі проти бота, не у змагальній партії.
- Налаштування сітки карток і ефекту взяття, збереження для гостя/акаунта. Ефекти поважають налаштування руху та prefers-reduced-motion.
- Шахове завершення за часом і здачею враховує матеріал конкретної сторони: голий король, одиночний кінь, одноколірні слони та можливі блокувальні фігури суперника. Додано доказ нічиєї для певних незмінних пішакових бар’єрів. Це не універсальний пошук усіх можливих dead positions.
- Міграція 0007: account_devices. Випадковий HttpOnly ідентифікатор браузера зберігається лише як hash; взаємні матчі акаунтів зі спільним браузером не дають XP/рейтингу. IP не використовується як доказ мультиакаунта. Обхід через інший браузер або видалення cookie можливий; повна античит-система не заявлена.
- pg_dump/pg_restore, окрема перевірка відновлення, dry-run/apply для прострочених сесій, токенів, device hashes, прочитаних сповіщень, черг і старих незв’язаних кімнат очікування. Активні партії, історія та бухгалтерські ledgers зберігаються.
- Production-БД використовує перевірку TLS-сертифіката/hostname; недовірені proxy-заголовки за замовчуванням не приймаються, список довірених CIDR налаштовується явно. Реальний хостинг ще не перевірено.
- Оптимізовані підмножини Fixel: Latin/Cyrillic, потрібні символи й стандартні функції shaping; перевірені українські ґ/є/ї/і. Файли приблизно на 45% менші. Оригінали та SIL OFL збережено; додано відтворюваний генератор.
- README.md англійською, README.uk.md українською. Посилання на живий сайт очікує майбутнього розгортання.
- Локальний Git, перевірка майбутніх файлів через Gitleaks, CI зі скануванням історії та Chromium/Firefox/WebKit. Користувач дозволив push у andrew-berezovskyi/playboard; deployment не виконується.

## Перевірено

- npm run check: TypeScript, ESLint, frontend/backend build, 60/60 Vitest на окремій PostgreSQL.
- Справжній backup/restore із зовнішніми ключами, UUID та JSONB у новій ізольованій БД; тестова БД прибрана після перевірки.
- Maintenance dry run: SQL-запити всіх політик виконалися успішно, дані не видалялися.
- npm audit: 0 відомих вразливостей на момент перевірки.
- Мобільний Lighthouse 13.5 для локальної production-збірки: performance 90, accessibility 100, best practices 100; LCP 3.2 s, CLS 0, TBT 20 ms. Це один лабораторний cold-load вимір зі стандартним мобільним throttling, не реальні польові Core Web Vitals. LCP ще має простір для покращення.
- Фінальна повна браузерна серія: 14/14 Playwright (6.9 min), включно з усіма курсами, реальними двома клієнтами, reconnect/rematch, мобільними Firefox/WebKit, адаптивною матрицею та автоматичним WCAG-аудитом. Латинські/українські метрики оптимізованого Fixel збігаються з оригіналом. Підготовлені файли не містять знайдених Gitleaks секретів; сканування історії виконується перед push.

## Незакриті вимоги після публікації

Довільні рідкісні FIDE dead positions поза реалізованими доказами; спеціальна негайна IDF-нічия без додавання з суддівським винятком очевидного виграшу; тривалий баланс Wayline; комплексне виявлення мультиакаунтів/сторонніх рушіїв; фізичні iPhone/Android та ручний аудит доступності. Публічна SMTP-доставка, фактичний proxy/TLS, квоти та розклад backup перевіряються окремо. Універсальної готовності всіх вимог ТЗ не заявлено.
