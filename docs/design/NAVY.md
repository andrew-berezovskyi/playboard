# Playboard — напрям інтерфейсу

Поточні рішення користувача: Playboard, Fixel, мінімалізм у дусі Linear. Navy Blue #062045 збережено для акцентів і активної навігації. Основний фон #111318, поверхні #191c23, другорядний текст #9ca5b4. Світла тема має власні контрастні токени.

Логотип — власна заокруглена дошка з двома клітинками й двома фішками. В шапці — прапор поточної мови, тема й компактний аватар; вихід у налаштуваннях. Немає версій, технічних підписів «локальна розробка» чи декоративних продуктових фотографій.

Fixel віддається локально у WOFF2 із font-display:swap, ліцензія SIL OFL додана. Дошки, фігури, прапори й навчальний провідник — SVG/CSS. Клітинки квадратні, зовнішні контейнери заокруглені. Анімація ходу 180ms, вимикається в налаштуваннях або через prefers-reduced-motion.
